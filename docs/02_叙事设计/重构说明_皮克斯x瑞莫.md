## A. 火星救援 × 皮克斯叙事方法

### 用了皮克斯的什么

| 方法 | 出处 | 落地 |
|---|---|---|
| **Want vs Need** | 皮克斯故事圣经核心：表层欲望 vs 深层需要，追 Want 的过程逼出 Need | Want = 撑过 27 小时回家；Need = 从「替补」到「守站人」的自我认同 |
| **Story Spine** | Once upon a time → Every day → Until one day → Because of that… → Until finally | 新增序章"日常拍"：巡检/报平安/数日子 → 沙尘暴打破日常 |
| **All is Lost 低谷** | 外部目标崩塌 + 内在缺陷暴露的最低点 | L4 二次风暴：曙光号可能中止降落 + 主角说出"替补守不住基地" |
| **法则 #1（敬佩尝试）** | People admire a character for trying | 失败结局改写：救援队长报告"坚持自救至第 25 小时" |
| **法则 #6（把反面砸给他）** | 角色舒适什么，就砸什么 | 替补 = 一直躲在正选背后的人 → 全部 5 关都是孤身决策 |
| **法则 #16（赌注）** | 不成功会怎样？ | 每关 HUD 数值实时扣，失败不是文案而是结局分流 |

### 关键改动摘录

序章（Want/Need 双线埋设 + Story Spine 日常拍）：

```renpy
"你叫 [player_name]。编制表上的头衔是：{b}替补{/b}驻留科考员。"
"正选驻留员老周，第 214 天因腰伤随最后一班飞船撤离。走前他在舱壁贴了张纸条——你一直没敢细看。"
"过去三天你的日常是：巡检，发报平安，在心里数曙光号接你回家的日子。"
"直到今天。"
```

All is Lost（L4，内在缺陷在谷底暴露，检视物在此回响）：

```renpy
me "……派我来的时候他们就说了，我只是替补。替补守不住一座基地。"
if detail_log:
    "黑暗里，你又看见舱壁上老周那行压得很重的字：{b}留下的人，就是守站人。{/b}"
ai "过去 21 个小时里做出全部决定的，不是「替补」——是你。"
```

结局按 Want/Need 双轴收口：

| 结局 | Want（回家） | Need（自我认同） |
|---|---|---|
| 完美 | ✅ | ✅ 队长撕掉「替补」胸牌，登记为首任守站人 |
| 生还 | ✅ | 半达成：「下个轮换期，正选名单有你」 |
| 艰难 | 勉强 | 未达成，但获得"敬佩尝试"的尊严书写 |
| 隐藏 | ✅ | 超越：主动申请回来——留下不是因为被留下 |

原有四轴系统（后果/HUD/机制/环境叙事）**全部保留**，皮克斯层叠在其上。

## B. 普林斯顿线 × 瑞克和莫蒂重构（全量重写）

### 用了瑞莫的什么

**1. Dan Harmon Story Circle 8 拍**（瑞莫每集的结构骨架，Harmon 本人的"故事胚胎"）——旧版是 20 镜讲座式平铺，你是听众；新版你是完整走完一圈的主角：

| 拍 | Story Circle | 新版剧情 |
|---|---|---|
| 1 You | 舒适区 | 今天，天文馆门口，"一秒就是一秒" |
| 2 Need | 裂缝出现 | **你的导航把你导进河里**（`ep1_gps_bug = True`） |
| 3 Go | 跨过门槛 | 空气撕开一个洞 → 1933 普林斯顿（瑞莫传送门式转场） |
| 4 Search | 试炼适应 | 三连：戳破以太幽灵 → 迈克尔逊-莫雷赛马 → 火车照镜子 |
| 5 Find | 找到答案 | 核心揭示：光速恒定，宇宙限速牌 |
| 6 Take | 付出代价 | 追光（怀表当场撕开 γ=7.09）+ **你亲手给双胞胎哥哥选速度** |
| 7 Return | 回到熟悉世界 | 回到今天 → **伏笔收割：导航是爱因斯坦关的修正开关** |
| 8 Change | 带着改变 | "光没变，变的是你" + 命名星 |

第 2 拍种的 GPS 故障在第 7 拍闭环——这是瑞莫最典型的"环形回收"，也同时是四轴里的延迟后果。

**2. 天才-搭档动力学**（Rick/Morty 二人组，全年龄化）：

```renpy
ein "迟到四十三秒。按你们的钟算。按我的钟算——无可奉告。"
ai "教、教授！这位是 [player_name]，导航把 TA 带进河里了——"
ein "我知道。是我关的修正开关。"
```

- 爱因斯坦 = 毒舌天才：不耐烦、跳跃、口头禅（"跟上，别眨眼""问得蠢，但蠢得很有代表性"），偶尔炸出温柔（未寄出的信、双胞胎那句"抓紧你手里的钟"）
- 小艾 = Morty 型搭档：结巴、紧张、**代观众提问**（"以太听起来挺合理的呀？""38 微秒这么点也要管？"）——观众想问的蠢问题都由她挨怼，玩家不用当傻子

**3. 代价感（Take 拍是瑞莫的情感核心）**：旧版双胞胎是旁观计算题；新版**你亲手按下按钮**，小艾拦你（"这可是别人的十年"），教授逼你（"科学从不合适。按。"）——知识点没变（γ=1.67/2.29/7.09），但从算术题变成了道德重量。

### 四轴同步落地（普林斯顿线首次全套）

| 轴 | 实装 |
|---|---|
| 后果系统 | GPS 伏笔跨 5 拍回收；`twin_v=0.99` 在命名星结尾回响（"隔着 γ=7 的岁月看同一颗星"）；`ep1_score` 决定教授三档评语 |
| diegetic UI | **教授的黄铜怀表**（`screen watch()`）：双表盘"你的时间 vs 地球时间"+ γ 实时值，追光瞬间左盘凝固右盘疯转 |
| 机制化 | 你亲手选双胞胎速度定 γ；亲手开/关 GPS 修正开关看导航崩掉 |
| 环境叙事 | 书房检视物：光速纸条 / 小提琴（"别碰。它比你诚实"）/ **未寄出的信** → 在 Take 拍情感回响；"什么都不看"也有专属反应 |

### 尺度控制

瑞莫的 R 级元素（酗酒/虚无主义/脏话）全部剔除，保留的是：结构（Story Circle）、节奏（快、每拍有梗）、动力学（天才×搭档）、meta 感（轻量，如结尾"下次别再关别人导航了行吗？！"——不破坏科普可信度）。
