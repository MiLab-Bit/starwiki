# 火星救援 Demo 升级说明 —— 做了什么、按什么方向做的

> 目的：让你对照判断升级方向是否正确。所有代码摘录均来自当前工程实文件，非描述性吹嘘。

---

## 一、原版交付包为什么"浅"（诊断）

| # | 原版短板 | 具体表现 |
|---|---|---|
| 1 | **选择无后果** | 选项只影响当句台词，选完即忘。选 A 选 B 殊途同归，玩家没有"我的决定塑造了故事"的感觉 |
| 2 | **科普靠嘴说** | 知识点全是 NPC 念课文（"你知道吗，火星大气 95% 是 CO₂……"），玩家是听众不是参与者 |
| 3 | **零沉浸感** | 纯色块背景 + 无音频 + 无任何界面反馈，状态（氧气还剩多少？）全靠台词口播 |
| 4 | **世界是空的** | 场景只是对话的幕布，没有可探索、可发现的东西，没有隐藏层 |

## 二、按什么方向升级（四轴方法论）

研究来源：互动叙事（ink/Twine 社区的延迟后果原则）、XR 叙事（presence + diegetic UI）、环境叙事（Henry Jenkins 四模式）、科普严肃游戏（"机制即论点"，mechanics-not-text）。

| 轴 | 方法论核心 | 落地手段 |
|---|---|---|
| ① 叙事后果系统 | 延迟后果 > 即时后果；不可逆抉择制造重量；NPC 记住你做过的具体事 | 全局状态机 + 跨关卡回响 |
| ② 沉浸多感官 | diegetic UI（界面属于故事世界，不是游戏菜单）；声音先于画面建立空间 | 舱内 HUD + 通讯滚条 + 合成音效 |
| ③ 科普机制化 | 知识不是台词，是玩家必须操作的参数——答错会真的付出代价 | L3 制氧 = 进气源 × 功率分配 |
| ④ 环境叙事 | 世界里埋线索，看不看由玩家决定；看了的人在结局获得回响 | 每关可检视物 + 隐藏结局钩子 |

## 三、逐轴实证（剧本摘录 vs 原版对照）

### ① 后果系统：不可逆抉择 + 跨关卡回响

原版：取水失败 → 一句安慰 → 剧情照常。

现在（`mars_rescue.rpy` L2）：

```renpy
"放弃钻探，回基地省着用（永久无水）":
    $ gave_up_water = True
    "你带着空货舱返回。水必须严格配给了——而且，再没有冰芯可电解制氧。"
    ai "记下了：接下来 24 小时，每一毫升都要精打细算。这条路，回头不了了。"
```

后果在 **下一关** 才兑现——L3 想用"电解水制氧"这条路时：

```renpy
"冰芯融水 → 电解水":
    if water_found:
        $ o2_src = "ice"
    else:
        "水箱本就见底，电解几分钟就被迫停机。"
        ai "没有冰芯储备，这条路走不通。已自动切回舱外大气。"
```

L5 会合时 NPC 有**具体记忆**（不是笼统的"干得好"）：

```renpy
if fix_first == "comm":
    cmd "你当初抢修的天线，让我们能把改到东侧谷地的着陆点传给你——还记得吗？"
```

状态机全貌（`mars_rescue.rpy` 头部，21 个持久化变量）：
`mars_score / fix_first / water_found / gave_up_water(不可逆) / oxygen_ok / power_ok / comm_ok / found_signal(隐藏结局钩子) / o2_pct / power_pct / mars_clock / mars_objective / detail_log / detail_rover / detail_photo / detail_wave / o2_src ...`

### ② 沉浸多感官：diegetic HUD + 音效

原版：无任何界面，氧气余量靠台词念。

现在（`screens.rpy`）：常驻舱内 HUD——O₂ 百分比（低于 40% 自动变红）、蓄电池、任务钟、当前目标、警报态；底部通讯滚条实时显示指挥中心/曙光号的最后一条讯息。这是**故事世界里的宇航服目镜**，不是游戏菜单。

音频（`game/audio/`，程序合成占位，后续可换真实音源）：
- `amb_hum.wav` 基地低频环境音（55+110Hz 循环）
- `sfx_alarm.wav` 警报（880/660Hz 交替）
- `sfx_blip.wav` 操作确认音、`sfx_signal.wav` 信号下滑音

### ③ 科普机制化：知识 = 你亲手调的参数

原版：NPC 念"MOXIE 能电解 CO₂"。

现在（L3）：玩家必须做两次真实决策，数值真实结算——

```renpy
"高功率（快，吃电 30%）":
    $ power_pct = max(0, power_pct - 30)
    $ gain = 35 if o2_src == "co2" else (20 if o2_src == "ice" else 5)
...
$ o2_pct = min(100, o2_pct + gain)
"制氧机嗡鸣。氧罐 +[gain]%，当前 [o2_pct]%。蓄电池剩 [power_pct]%。"
```

- 选 CO₂ 直接电解 → 效率最高（这就是毅力号 MOXIE 的真实原理，玩家用行动学会）
- 选电解水 → 可行但烧掉饮用水（资源权衡）
- 选藻类 → "方向浪漫，速度感人"（时间尺度概念）
- 功率分配吃掉的电，会影响 L4 沙尘暴的生存空间——**这里省的电就是那里的命**

### ④ 环境叙事：埋线 + 隐藏结局

- L1 检视物：前任驻留员的日志贴纸（『留我守站。』）、受损巡视车、舱壁地球照片——看不看自由，看了的在结局有回响：

```renpy
if detail_log:
    "你想起舱壁那张日志贴纸：『留我守站。』——现在，它不再是一句遗言，而是一份交接。"
```

- 隐藏线：L2 二次钻探时地震仪记录到 **26.7 秒周期的规律微震**（`found_signal = True`），通向第 4 个隐藏结局《寂静的信号》——只有"扑空后坚持再钻"的玩家才可能触发。这是给复玩者的奖励，也是"科学不怕试错"主题的机制表达。

## 四、结构与结局树

```
序章 → L1 损伤评估(检视物+首修抉择) → L2 取水(3选1+失败支线+不可逆抉择)
     → L3 制氧(源×功率机制) → L4 能源·沙尘暴(风险决策+支流分支 mars_l4_risk)
     → L5 会合(通讯信息差决定难度)
     → 结局×4：完美救援 / 27小时生还 / 艰难归途 / 隐藏·寂静的信号
```

视觉：全部 NASA 公版实拍图（沙尘暴 PIA22519 / 地表 PIA11428 / 极冰 PIA10651 / ISS 舱内 iss017e015059 加红色警报调 / 指挥中心），零版权风险。
