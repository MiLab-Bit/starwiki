| 项 | 说明 |

| 形态 | 单人可玩叙事关卡 / 沉浸式科普剧 |

## 2. 线 A ·《航向火星·救援队归来》

### 核心命题

替补驻留员独自撑过约 27 小时等救援，并在过程中成为「守站人」。

| 轴 | 内容 |
|---|---|
| Want | 撑过危机、回家 |
| Need | 从「替补」到「守站人」的自我认同 |
| 带走 | 选择有重量；一次可复述的科学动作（取水 / 制氧）；想再试一条修法 |

### 主路径节拍（约 16 分钟）

1. **开场** — 风暴砸日常，身份落成「替补」
2. **密室气闸** — 检视线索、拼码、首修抉择
3. **取水** — 选钻探点（永久阴影区 vs 伪湿润）
4. **制氧** — 调参（进气源 × 功率），看见数值因果
5. **谷底风暴** — 风险抉择，All is Lost
6. **会合** — 通讯有无决定路径；信息差兑现
7. **结局** — Want / Need 双轴结算

### 玩法动词（仅四个）

检视 · 抉择 · 调参 · 承受

### 结局（馆内运营）

| 结局 | 运营提示 |
|---|---|
| 完美·红土重逢 | 高分；可选展示 |
| 生还·27 小时 | 中分；默认主推 |
| 艰难·第 25 小时 | 低分；失败也可敬 |
| 隐藏·寂静信号 | 特殊触发；不首播剧透 |

原则：主路径保证可到「生还」或「完美」；失败路径须能自救到「活着离场」。

## 3. 线 B ·《回到普林斯顿》第 1 集

### 核心命题

导航把你导进河里——1933 普林斯顿，爱因斯坦带你弄坏又修好「时间」。

| 轴 | 内容 |
|---|---|
| 结构 | Dan Harmon Story Circle 八拍 |
| 动力学 | 爱因斯坦＝毒舌天才；小艾＝代问搭档；观众＝动手的人 |
| 带走 | 「一秒不是对所有人都一样」；GPS 在用相对论；轻量回访钩子 |

### 八拍节拍（约 16 分钟）

1. **You** — 「一秒就是一秒」
2. **Need** — 导航失灵，常识裂缝
3. **Go** — 进入书房，拿到怀表
4. **Search** — 以太 / 赛马 / 火车镜子三连试炼
5. **Find** — 光速恒为 c
6. **Take** — 追光抉择、双胞胎速度；**怀表双盘撕裂**（必达 Wow）
7. **Return** — 回到今天，相对论修正与 GPS
8. **Change** — 「光没变，变的是你」；收口与命名星

早期 20 镜分镜降级为**零件箱**：本集默认锁八拍；不足时长可回补「拨慢时间看光爬行」一块。生日星图、长哲学独白不进本集。

### 玩法动词（仅四个）

检视 · 质疑/抉择 · 定参 · 点亮

### 角色声音闸门

- 爱因斯坦：短句、跳跃、损人不脏；禁止慈祥导游腔与长段念经
- 小艾：代观众提问，观众不必当傻子
- 史实可保留 1933 赴普林斯顿；出图风格化，不用历史照片脸
