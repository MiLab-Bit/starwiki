## 0. 总原则（审美再抬一档靠这个，不靠加细节）

1. **环境先说话，人再开口**（Yōtei 艺术指导逻辑）：气氛与威胁在台词前到位。  
2. **加细节救不了废构图**；先过色脚本 → 灰阶 → 剪影 → 再生成/精修。  
3. **空景建世界；有半隐面罩的人，才建命运。**  
4. **审查只认 PC 16:9 满屏**（1920×1080 / 2560×1440），不以手机宽为标准。

## 1. 人进景锁定（已拍板）

| 项 | 决定 |
|---|---|
| **玩家呈现** | **面罩可辨的半隐**——非无面背影、非明星脸特写 |
| **可读** | 头盔/面罩块面可辨；面罩内可有冷青 HUD 反光或模糊五官；**不认脸**；中近景 **S2 替补胸牌**尽量可读 |
| **站位** | 三分点；面朝压力源（尘墙/气闸/伞）；留视线空间 |

| **小艾** | 对话半身立绘；冷青体系与玩家头盔灯同源，不抢 S1 |
| **审查画幅** | **PC 16:9 满屏** |

### 1.1 人进景剂量表（按戏用药，非每张大头）

| 类型 | 画幅占比 | 用法 | 典型镜 |
|---|---|---|---|
| **远景半隐** | 约 3–8% | 头盔块面仍可读；建立尺度与命运 | HK1、HK5、HK6 |

## 2. 审美四层（工业上游，出图前必过）

### 2.1 色彩脚本（按节拍，不按单张）

全片只准一条色温时间轴；单张必须落在对应格，否则「每张都像封面、连不成片子」。

| 节拍 | 主色（≤3） | 意图 |
|---|---|---|
| 开场风暴 HK1 | 低饱和锈红 + 尘灰 + 逆光冷白缘 | 压迫 |
| 舱内警报 HK2 | 血红染 + 一点冷青仪表 | 封闭恐惧 |
| 取冰 HK3 | **冷青灯柱主导** + 深冷阴影 | 科学动作 |
| 制氧（复用 HK2） | 同舱，红略收、青略稳 | 操作感 |
| 谷底 L4 / HK5 | **最暗、近单色锈灰** | All is Lost |
| 伞降 HK4 | 锈红里切开 **一点白/微暖** | Want 兑现 |
| 菜单 UI1 | S1 锈红场 + S2 物件；标题负空间 | 品牌 |

冷青点面积永远小于锈红场。

### 2.2 明暗结构（Value）

- 概念先过**灰阶**：缩成黑白仍知看哪。  
- 亮部只留给戏眼：尘缘 / 冰晶 / 伞 / 胸牌 / 面罩反光。  
- **满屏中间调**＝业余感主因，退回。

### 2.3 形状语言（剪影）

- 玩家在远景：只留黑影也应读出**头盔块面 + 服形体**。  
- 胸牌在中景：小矩形应进剪影或高光。  
- 生成前后做一次**剪影测试**（压暗成黑形贴在背景上仍成立）。

### 2.4 人进景构图语法

- 人在三分点，少居中明信片。  
- 视线看向画内压力源，留视线空间。  
- 广角建立尺度时负空间可以很大，但半隐面罩必须是情绪锚。  
- 用轮廓光 / 剪影明暗差做人景分离。

## 6. 上游管线（每次出图按此，吸取工业流程）

```
① 看色脚本落在哪一格
② 2 分钟灰阶构图草图（人位置 + 戏眼亮部 + S1/S2/S3）
③ 再生成 / 绘制
④ 剪影测试 + 灰阶测试
⑤ 手动收：轮廓光、减中间调、统一笔触、胸牌/面罩可读
⑥ PC 16:9 满屏跑「审查五步」
```

---

## 7. PC 审美审查五步（每张 约 60 秒）

1. **1920/2560 满屏**——2 秒内眼睛落点是否在「半隐面罩 / 符号 / 戏眼」？  
2. **去色**——主次还在吗？满中间调则退。  
3. **遮住人**——若完全不影响叙事，人是废话（英雄帧不合格）；若崩了，人是主语（好）。  
4. **剪影**——头盔块面是否还在？  
5. **对色脚本**——是否跳戏（谷底变成鲜艳旅游照＝失败）？

过不了 1–4，禁止靠加细节补救。
