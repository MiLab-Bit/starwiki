## 0. 总原则（与火星清单同源）

1. **环境先说话，角色再开口。**  
2. **加细节救不了废构图**；色脚本 → 灰阶 → 剪影 → 再生成/精修。  
3. 本集画面主语是 **怀表 + 教授面容**，不是空书房。  
4. **审查只认 PC 16:9 满屏**（1920 / 2560）。  
5. 与火星 **色温生死对立**——混用即失败。

## 2. 审美四层（上游必过）

### 2.1 色彩脚本（Story Circle 8 拍）

| 拍 | 主色（≤3） | 意图 |
|---|---|---|
| 1 You | 夜蓝穹顶 + 手机冷屏 | 舒适乏味 |
| 2 Need | 同今天 + 荒谬导航色 | 裂缝 |
| 3 Go | **暖褐木墙 + 烛火琥珀 + 黑板深青** | 温度层建立 |
| 4 Search | **幽蓝**实验室，暖褐退场 | 试炼 |
| 5 Find | 黑底 + **金色字幕/星** | 圣言一拍 |
| 6 Take | 深空冷 + **黄铜怀表暖点** | 代价 Wow |
| 7 Return | 夜蓝；导航青点归位 | 闭环 |
| 8 Change | 银河 + **暖金命名星** | 变的是你 |

禁止书房进锈红；禁止实验室赛博紫。

### 2.2 明暗（Value）

亮部只给：壁炉 / 窗光 / 怀表盘 / 星点 / 眼镜反光。满中间调暖色插画＝退回。

### 2.3 剪影（Shape）

- 教授：乱发 + 微驼 + 表链 → 远距可辨  
- 小艾：更年轻块面、缩肩 → 与教授不可互换  
- 怀表：双盘圆 → 缩成图标仍识

### 2.4 构图语法

教授三分点，留损人视线空间；怀表微距双盘同框；点星时人小星大或手触穹顶。

## 7. PC 审美审查五步（约 60 秒）

1. 满屏——2 秒落点在教授面容 / 怀表 / 星 / 壁炉？  
2. 去色——戏眼还在？  
3. 遮住教授——对话英雄帧若毫不受损＝景抢人（不合格）  
4. 剪影——乱发驼肩 / 双盘圆是否可辨？  
5. 色脚本——是否污染锈红或赛博紫？
