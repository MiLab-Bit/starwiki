## 产品一句话

一套**双线可玩剧情 Demo**：馆内约 15–20 分钟单人体验，首页可选进入火星救援线或普林斯顿科普剧线。

### 《航向火星·救援队归来》

沙尘暴后的启明基地，氧气、电力、通讯告急。玩家以「替补」守站人身份，在向导小艾陪伴下完成评估、取水、制氧与能源调度，赶往会合点。四个核心动词：**检视 / 抉择 / 调参 / 承受**。选择影响结局——留下的人，就是守站人。

### 《回到普林斯顿》第 1 集

导航失灵，跌入 1933 年的普林斯顿，遇见阿尔伯特。按 Story Circle 八拍推进：以太、相对性、时间膨胀，到怀表双盘撕裂的 Wow，再回到今天理解 GPS 与相对论。四个核心动词：**检视 / 质疑 / 定参 / 点亮**。

主题曲：《The Road Home / 星河有归》。
