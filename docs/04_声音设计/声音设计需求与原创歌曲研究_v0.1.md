# 声音设计需求书 × 原创歌曲创作研究 · v0.1

> **出品**：上海端点星幻境科技 · 天文馆 XR 剧情 Demo  
> **范围**：本期 Ren'Py 可玩样片（双线 15–20 分钟）+ 可迁移至馆内 XR / 穹顶呈现层的听感规格  
> **状态**：需求锁定前讨论稿（先定规格，再写词 / 作曲 / 制作）  
> **现状**：工程内仅 4 个程序合成占位音（`amb_hum` / `sfx_alarm` / `sfx_blip` / `sfx_signal`），**无真实 BGM、无主题曲、无环境层**

---

## 0. 一句话定位

声音不是「加 BGM」——它要完成三件事：

1. **世界辨识**：火星锈红纪实 vs 普林斯顿暖褐胶片，一耳可分；  
2. **情绪节拍**：与策划案分钟表同构，尤其 L4 谷底静默、怀表 γ 撕裂、命名星收口；  
3. **品牌记忆**：一首可带走的原创主题（或双主题变奏），证明端点星幻境有「内容 IP」而不只是工程外包。

对外说法（防范围蔓延）：

> 「本 Demo 声音方案含环境层、互动 UX、双线情绪配乐，以及端点星幻境原创主题曲样片；环绕声 / 穹顶空间化属合同二期呈现层，本期先交付可循环立体声母版。」

## 1. 现状诊断（必须正视）

| 项 | 现状 | 风险 |
|---|---|---|
| 占位音 | 4 个短波文件，无乐句 | 馆方会听成「PPT 配音效」 |
| 接入点 | 火星有 hum/alarm/blip；普林斯顿几乎只有 signal/blip | 暖调世界没有听觉温度 |
| 策划债 | 火星策划 §8 要求 L4「3–5 秒静音」；普林斯顿要求拍 5「静音一拍」 | 代码未实现「主动静默」 |
| 歌曲 | 无 | 缺可传播的品牌钩子（短视频/评审回味） |

战略判断书已标「音频占位 = 中风险」——本阶段就是把它抬到「可示人」。

## 2. 声音分层架构（先锁层级，再写曲）

采用博物馆/沉浸展常用的 **四层叠放**（参考 AAM 沉浸声实践、Melbourne Museum TYAMA、Franklin Institute Wondrous Space）：

| 层 | 代号 | 功能 | 本期 Ren'Py | 二期 XR/穹顶 |
|---|---|---|---|---|
| L0 环境 | AMB | 空间在场感（风、舱压、壁炉木裂、书房时钟） | 立体声循环 | 可升为空间化 |
| L1 配乐 | BGM | 情绪弧与主题变奏 | 立体声，按场景 `fade` | Stem 可分轨 |
| L2 歌曲 | SONG | 品牌记忆 / 片头片尾 / 结局仪式 | 完整曲 + 无人声 Instrumental | 可做短视频衍生 |
| L3 互动 | SFX/UI | 确认、警报、怀表滴答、通讯破音 | 短 one-shot | 可按交互触发 |

**叠放原则（馆内硬约束）**

- 对话永远最前；BGM 在有对白时压到 −12～−18 LUFS 相对对白。  
- 警报/关键 SFX 可短暂盖过 BGM，但 **禁止持续刺耳**（亲子场）。  
- **静默是设计**，不是没素材：L4 / 光速揭示拍必须能 `stop music fadeout` 到近静音。  
- 两线 **禁止共用同一条主旋律**（色温对打的听觉版）；允许共用「端点星」超级短动机（2–4 音）作品牌水印。

## 5. 原创歌曲创作研究

### 5.1 为什么要有「歌」，而不只是 OST

| 目的 | 说明 |
|---|---|
| 评审记忆 | 馆方散场后能哼出一句，比记住「我们有关卡系统」更强 |
| 传播物料 | 15s/30s 短视频、方案 PDF 二维码试听、展项导览预告 |
| IP 证据 | 证明端点星幻境有原创内容产能，对打「大厂模板展项」 |
| 双线粘合 | 一首主题、两种编曲变奏，比两首无关流行曲更像「同一馆的声音宇宙」 |

参考线索（方法论，不抄旋律）：

- **博物馆沉浸**：声音与情绪/认知弧同步设计，而非后期贴曲（AAM / Art Processors 思路）。  
- **天文馆 fulldome**：如 *Tycho Goes to Mars*——原创配乐服务叙事+科普，母版可再空间化。  
- **游戏主题动机**：短动机可变奏贯穿（米哈游等常用「战斗/区域动机」做法）——我们用 **4 音端点星动机** 即可。  
- **无词 vs 有词**：无词哼唱跨年龄更安全；有词则必须过「馆方审校 + 全年龄 + 不剧透二季」。

### 5.2 歌曲产品形态（建议锁定一种主推）

| 方案 | 形态 | 优点 | 风险 | 建议 |
|---|---|---|---|---|
| **A. 馆歌式主题曲** | 中文主歌+副歌，2:45 左右 | 最好记、最好传播 | 歌词审校、演唱人设 | **主推** |
| B. 无词圣咏/哼唱 | 女声或童声啊啊，2:00 | 全年龄、少审校 | 品牌句难落地 | 作副产品/国际版 |
| C. 双线双主题 | 火星一首 + 普林斯顿一首 | 个性强 | 产能翻倍、记忆分散 | P2 |
| D. 纯器乐主题 | 无唱 | 最快落地 | 传播弱 | 作 Instrumental 必出 |

**本期建议**：**方案 A 完整版 1 首 + Instrumental 1 首 + 4 音动机**；火星/普林斯顿用动机变奏进 BGM，不各写一首完整流行歌。

### 5.3 主题曲「听感 brief」（给作词作曲用）

| 项 | 锁定建议 |
|---|---|
| 工作标题（可改） | 《点亮你的名字》或《守站人》或《一秒之外》——**三选一前先定叙事锚** |
| 叙事锚 | 推荐锚定 **「把名字写进星图」**（双线收口都有星图/命名）——比单绑火星或爱因斯坦更中性 |
| BPM | 72–96（馆内可走，不嗨不丧） |
| 调性气质 | 大调底色 + 一段小调桥（对应「谷底/裂缝」），副歌回大调 |
| 编曲 | 钢琴/弦乐为主；副歌可加极克制合成星尘；**不要 EDM drop** |
| 结构 | Intro(动机) → A → A2 → B副歌 → Bridge（静/低） → B' → Outro(动机+星点) |
| 时长 | 完整 2:30–3:30；另剪 **15s / 30s / 60s** 传播版 |
| 人声 | 一名主唱即可；和声克制；童声可选一层远景（慎用，防广告感） |
| 语言 | 普通话；避免网络梗、避免「打卡」「元宇宙」口号词 |
| 禁用词 | Pico、竞品名、过度承诺「改造火星」伪科学口号 |

### 5.4 歌词创作闸门（比旋律更先锁）

歌词必须过四道门：

1. **科学门**：不写错相对论/火星制氧；隐喻可以，假事实不行。  
2. **年龄门**：亲子场可听；无恋爱情欲、无虚无「宇宙冷漠」堆砌。  
3. **品牌门**：可点「端点」「星图」「一秒钟的距离」；不硬塞公司全名进副歌。  
4. **剧透门**：不剧透隐藏结局、不剧透第 2 集方案。

**意象池（可写）**

- 火星：替补、守站、尘暴后的清晨、氧气从二氧化碳里「挤」出来（诗意化，不念公式）  
- 普林斯顿：怀表双盘、光不等人、河岸与导航、壁炉与黑板  
- 共用：把名字点进穹顶、回家的路有时是留下来

**意象池（勿写）**

- 外星人入侵、恋综感告白、励志鸡汤空壳、「征服宇宙」

**副歌功能句（示例方向，非正式定稿）**

> 不是要你记住公式，  
> 是要你记住——有一颗星，因为你亮过。

（正式歌词需单独开一版稿，过审后再录。）

### 5.5 歌曲与体验的挂接位置（产品设计）

| 挂接 | 用法 |
|---|---|
| 主菜单 | Instrumental 循环 60s 摘段 |
| 普林斯顿拍 8 命名星 | 副歌器乐版淡入，人声可无 |
| 火星完美结局 | 副歌变奏（更空灵/更暖） |
| Demo「关于」页 | 不自动播完整歌（防吵）；可放「试听」按钮（P1） |
| 对外物料 | 30s 版 + 公司片头 LOGO 同步 |

### 5.6 创作与制作管线（建议工序）

```
① 锁 brief（本文 §5.3–5.4） 
② 定工作标题 + 副歌一句（你拍板）
③ 作词 v1 → 审校（科学/年龄/品牌）
④ 作曲 demo（钢琴+唱）→ 听感确认
⑤ 编曲 / 录音 / 混音
⑥ 导出：完整有词 / Instrumental / 15·30·60s / loop 摘段 / 干声 stem（可选）
⑦ Ren'Py 接入 + 响度统一
⑧ （二期）穹顶/XR 空间化与分轨
```

**产能现实**：完整主题曲是关键路径上的「半周–两周」级任务（视是否外请人声）；P0 的 AMB/BGM/SFX 可并行先做，**不要卡在等歌**。

### 5.7 技术规格（Ren'Py 本期）

| 项 | 规格 |
|---|---|
| 格式 | `.ogg`（Vorbis）优先；或 48kHz 16-bit WAV 再压 |
| 响度 | 配乐循环约 −16～−18 LUFS；SFX 峰值勿削波；对白预留头部空间 |
| 循环 | 需提供 **无缝 loop**（或标注 loop 起止采样点） |
| 命名 | `audio/` 下短英文 ID，与 §4 表一致 |
| 版权 | **原创作词曲 + 录音版权归端点星幻境（或合同约定）**；禁止临时用网易云/未授权曲 |
| AI 音乐 | 若用生成工具：必须人工精修旋律与歌词，并确认工具商用条款；**评审场建议主推真人制作叙事** |

### 5.8 参考听感（风格罗盘，非抄袭清单）

用「像什么气质」校准，不要求同曲风翻唱：

| 方向 | 参考气质 | 用于 |
|---|---|---|
| 火星纪实 | *The Martian* 配乐的克制电子+吉他尘感；游戏向如 *Juno* / 部分 *Outer Wilds* 的孤独空旷 | AMB + All is Lost |
| 普林斯顿暖学 | 室内乐、轻微怀旧电影感（避免过度华尔兹甜） | 书房 BGM |
| 主题曲 | 科普/馆藏向：可记副歌 + 星尘织体；接近「有词的穹顶片尾」而非流行热歌 | SONG |
| 怀表机制 | 机械钟表采样 + 微时间拉伸（audible γ） | SFX 程序联动 |

## 6. 工程接入需求（给后续 coding）

1. **通道**：`music` / `sound` / 可选 `audio ambient` 第三通道（Ren'Py 可用独立 channel）。  
2. **静默 API**：封装 `label audio_hush(seconds=4)`，火星 L4、普林斯顿拍 5 必调。  
3. **怀表音频**：`watch_gamma` 变化时切换 drip 速率或 pitch（可用 `renpy.music.set_pan` / 多采样切换，简单版先做两档）。  
4. **替换占位**：删除或降级 4 个合成波，避免「示人版仍像玩具」。  
5. **关于页文案**：可加一句「主题曲：端点星幻境原创（样片）」——不提 Pico。

## 8. 待你拍板的 5 个问题（定了才能开写词）

1. **主题曲叙事锚**：偏「守站人」 / 「命名星」 / 「一秒之外（相对论）」哪一个？
