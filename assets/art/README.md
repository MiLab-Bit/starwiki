# StarWiki · 美术资产

面向上海天文馆双线叙事 Demo 的美术交付包。本分支以**满配命名资产**为主，附引擎半身立绘裁切。

出品：上海端点星幻境科技有限公司  
制作：AIGC艺术家 · 吟游诗人Lab
